## Validation

The change includes browser regressions for light/dark focus, Contact continuation,
sample disclosure, direct opening after network failure, embedding refusal recovery, narrow-screen
navigation separation and keyboard graph exploration. Hydration coverage includes
all seven case studies. Unit tests use synthetic inputs and an in-memory database;
algorithm validators are offline. Auth/browser fixtures use local stubs and do not
load production credentials. Linux xvfb behavior still needs an actual hosted
Actions run after the change is pushed; a workflow edit is not a recorded CI run.

Final local results are recorded in the delivery note produced with this change.
Remote Actions success/failure runs and deployed smoke checks intentionally remain
pending under the owner's local-only instruction; workflow source is not a hosted
run. The original headed native-capability coverage is retained.
