## Keeping it minimal

I wanted the site to do exactly what it needed to do, and still be memorable. I
kept the layout minimal and put its character into the navigation controls.

## Navigating by colour

I used the palette as a navigation control. Each page starts with related
photographs; select a swatch to narrow them to that colour. It gives you another
way through the archive without a separate search interface.

Colour features are extracted on upload. Matching runs in the browser from cached
palette data, so changing the selected colour does not need another server request.

## Adding new work

A private admin area handles uploads, photograph details, and site text. Images are
checked before publication, with colour analysis built into the upload workflow.

I used Next.js for the archive and photo routes, with React handling palette
selection. The pages can be cached while colour matching runs in the browser.
Supabase keeps photograph metadata and admin authentication together; Cloudflare
R2 stores the originals separately from the application, so publishing the site
does not mean redeploying its image collection.
